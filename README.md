# seconddoor.live

The public welcome page for Second Door Live: what the platform does and who it's for. Plain HTML and CSS, no build
step, served by GitHub Pages at https://seconddoor.live (see `CNAME`). seconddoorlive.com redirects here with a
Cloudflare redirect rule.

The click-through demo with made-up data lives at https://second-door-live.github.io and is made from the
platform's own repository.

To look at it locally:

```bash
python3 -m http.server 8000
```
